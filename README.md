# StackFlow

StackFlow is a beginner-friendly Employee Management System built with Angular,
ASP.NET Core Web API, Entity Framework Core, and PostgreSQL.

## Project Status

The application is being developed and explained one phase at a time.

## Project Structure

```text
Stackflow/
├── stackflow-api/       # ASP.NET Core Web API
├── stackflow-frontend/  # Angular web application
├── docs/                # Learning notes and manual test cases
├── README.md
└── .gitignore
```
